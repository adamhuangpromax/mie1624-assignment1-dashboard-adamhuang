# MIE1624 Assignment 1 Dashboard

This folder contains a Streamlit dashboard built from the aggregated results and exact figures exported from the submitted Jupyter Notebook.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy

1. Create a GitHub repository.
2. Upload `app.py`, `requirements.txt`, and the `assets/` folder.
3. Open Streamlit Community Cloud.
4. Choose the GitHub repository and set the main file to `app.py`.
5. Deploy.
6. Open the public URL in an incognito/private browser window to confirm that no login is required.
7. Add the public URL to the first page of the report and, optionally, to the final section of the notebook.

No respondent-level survey data is included in this dashboard.
